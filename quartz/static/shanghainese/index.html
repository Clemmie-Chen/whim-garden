编订原则

音形相生沪拼表（下文称「本方案」）的基本体系引用自吴语学堂版本的吴语拼音（基于上海音系（中派），下文称「吴拼」），并朝新派上海话的方向做了简化改造。

考虑到歌词的注音对象为拼音使用者和英语使用者，为了让 TA 们更快地理解、上手、跟唱，因此在标音过程中，对原版吴拼做了一些改动——对于 IPA 和拼音的冲突，选择了大家更熟悉的拼音标法。

除拼写体系的修改之外，单字的注音也更多的基于实际的发音。如有词典未收录的发音（如：普通话词语文读），则以实际发音为准进行注音。如，咖啡的「咖」，实际读音为 /kʰa/(IPA)，吴语小词典只收录了咖喱的「咖 /kɑ/」，我们则按 /ka/ 来标记。

另，上海话本身区分单字调/连读变调，但考虑到连读变调及歌曲旋律对于声调的影响，歌词注音不标注声调。

  • 零声母调整：
    • 吴拼空置了零声母，歌词版本加上前置零声母以符合拼音使用者的习惯。如 乌 [u] /u/ → /wu/；衣 [i] /i/ → /yi/；淤 /ü/ → /yü/
    • 同时，对声门浊擦音也保留其零声母的使用，如 河 [ɦu] → /wu/；搿 [ɦəʔ] → /ɦəʔ/。不区分零声母和声门浊擦音的音位对立。
  • 龈颚擦音及塞擦音 /j/ /q/ /x/ 沿用普通话拼音方案：
    • 为防止拼音使用者混淆普通话的「几 [tɕ] /j/」和吴拼的「几 [tɕ] /ci/」，本方案把「几」按拼音习惯标为 /ji/，对应的浊「其」标为 /ʝi/。如 几 /ci/ → /ji/；其 /ji/ → /ʝi/
    • 为防止拼音使用者混淆普通话方案的「吃 [ʈʂi] /chi/」和上海话吴拼方案的「气 [ʈɕi] /chi/」，本方案把「气」按拼音习惯标为 /qi/。如 气 [ʈɕi] → /qi/
    • 为防止普通话方案的「诗 /shi/」和吴拼方案的「希 [ɕ] /sh/」混淆，歌词版吴拼把「希」按拼音习惯标为 /x/。如 想 [ɕ] → /xiaŋ/
  • 沿用普通话拼音方案，送气与不送气的塞音使用不同字母表示，浊音使用变体字母。
    • [p] [pʰ] [b] → /b/ /p/ /ɓ/，如 北、泼、葡
    • [t] [tʰ] [d] → /d/ /t/ /ɖ/，如 得、脱、夺
    • [k] [kʰ] [g] → /g/ /k/ /ɠ/，如 康、刚、戆
  • 遵循普通话习惯，不区分龈腭鼻音的清浊 /ʔȵ/日 - /ȵ/粘
